# Kaggle Hierarchical Synthetic Model Reproduction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package the existing Goal 1.5 hierarchical synthetic models as a private, hash-addressed Kaggle Model and prove CPU-only inference reproducibility in a private Kaggle notebook with Korean documentation.

**Architecture:** A deterministic package builder copies the existing baseline, STD-A, stage, and behavior artifacts into a logical payload, builds a wheel, creates a bounded validation-person sample, and archives the payload as `model_payload.tar.gz`. A strict inference module verifies both outer and inner hashes, checks `.skops` unknown types and feature schema, runs the selected hierarchical heads, and compares output with an immutable expected sample. Kaggle publishing is a fail-closed final adapter: local artifacts and notebook are fully verified before any private Model or Code upload.

**Tech Stack:** Python 3.12, pandas, PyArrow, scikit-learn, skops, Pydantic, nbformat, nbclient, uv, Kaggle CLI 2.2.4, pytest, Ruff, mypy

## Global Constraints

- Data status is exactly `oracle/sanity`; real wearable accuracy is exactly `NOT VERIFIED`.
- Device synchronization remains `NOT_AVAILABLE_TRUTH_ONLY`.
- The package remains a `candidate`; no promotion to `champion` or production language.
- Use the existing `mvp3-oracle-v1` artifacts; do not retrain, change thresholds, use GPU, or read locked test again.
- Kaggle Model and reproduction notebook are private.
- Kaggle framework metadata is exactly `scikitLearn`; variation slug is exactly `oracle-sanity-v1`.
- Never write or load `.pkl`, `.pickle`, or `.joblib` files.
- Before loading `.skops`, discovered unknown types must exactly match the manifest declaration.
- Keep hidden archetype, intensity truth, event truth IDs, and other forbidden truth columns out of model input.
- The existing 10GB synthetic Kaggle Dataset stays separate from the model package.
- Preserve unrelated worktree changes and do not print Kaggle credentials.
